# 就医导诊

## 科室选择速查

| 症状 | 首选科室 |
|---|---|
| 胸痛/胸闷/心悸 | 心内科（先排除心脏） |
| 胃痛/反酸/反胃/食道不适 | 消化内科 |
| 喉咙异物感/慢性咽炎 | 耳鼻喉科（同时排查反流） |
| 腹痛/腹泻/便秘/便血 | 消化内科 |
| 头痛/头晕/肢体麻木 | 神经内科 |
| 咳嗽/呼吸困难/胸痛 | 呼吸内科 |
| 关节痛/腰痛/脊柱问题 | 骨科 / 康复医学科 |
| 皮肤问题 | 皮肤科 |
| 失眠/焦虑/情绪问题 | 精神心理科/临床心理科 |
| 脱发 | 皮肤科 |
| 体检异常指标 | 对应专科（肝功能→消化/肝病、血糖→内分泌） |

## 常见检查项目

### 消化内科
- **胃镜**：看食管、胃、十二指肠黏膜，确诊反流性食管炎/胃炎的金标准
- **碳13/碳14呼气**：查幽门螺杆菌（已做，阴性）
- **24小时食管pH监测**：诊断难治性反流
- **腹部B超**：肝胆胰脾

### 心内科
- **普通心电图**：10秒快照，看心律和缺血
- **24小时动态心电图（Holter）**：统计全天早搏数量、心律失常
- **心脏彩超**：看心脏结构和功能
- **运动负荷试验**：看运动时是否缺血

### 呼吸科
- **胸片/胸部CT**：看肺和胸膜
- **肺功能**：排查哮喘

## 跟医生沟通的万能话术

> "我最近[多久]出现[什么症状]，[加重/缓解因素]，以前查过[什么检查]，结果是[什么]，没有[红旗症状]。想让您帮我看看是什么问题，需要做什么检查？"

### 通用话术模板
> "医生您好，我最近[多久]出现[什么症状]，[加重/缓解因素]，以前查过[什么检查]，结果是[什么]，没有[红旗症状]。想让您帮我看看是什么问题，需要做什么检查？"

### 反流/胸口不适话术示例
> "医生您好，我胸口正中阵发性不舒服，有时候会窜到喉咙，有反胃感但不反酸，平躺的时候容易犯，吃完饭会好一些。之前查过XX是阴性，心电图提示XX。想看看是不是胃食管反流，要不要做胃镜？"

## 宠物就医

### 猫
- 常规问题：猫专科医院 / 综合宠物医院
- 急重症：24小时急诊宠物医院
- 提前准备：说清年龄、疫苗史、症状开始时间、吃喝拉撒情况

### 乌龟/异宠
- 必须找**异宠专科**医院，普通猫狗医院可能看不了
- 去之前拍好：龟缸环境照片、水温计照片、粪便照片
- 说清：品种、养了多久、环境参数（水温/水位/晒背灯）、最近饮食变化
